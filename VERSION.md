# MiniKBP — что изменилось для пользователей

Документ для людей, не для разработчиков: только то, что видно в интерфейсе приложения, на сайте или в APK.

## 0.1.71 — последний push в git (`Reserve version`, 22.06.2026)

### Сайт и установка
- **Новая посадочная страница** на `mini-kbp.site`: описание приложения, превью журнала и расписания, ссылки на установку.
- **Отдельный раздел приложения** `/app` — вход, расписание, журнал и настройки в одном мобильном интерфейсе.
- **PWA / установка на телефон** — подсказка «Добавить на главный экран» и манифест для иконки на домашнем экране.
- **APK 0.1.71** в разделе загрузок на сайте.

### Расписание
- **Просмотр одного дня** с перелистыванием свайпом влево/вправо.
- **Полоска дней** (Пн–Сб) для быстрого перехода.
- Подсветка **«Сегодня»**, метки **«Сейчас»** / **«Ближайшая»** пара при включённом обратном отсчёте.
- Переключатель **«Показать замены»** по дням.
- Плотность отображения: обычная / компактная / мелкая.
- Поиск расписания по группе, преподавателю, аудитории, предмету.

### Журнал (студент, ej.kbp.by)
- Таблица оценок с **средним баллом** по предметам и итогом.
- Вкладки **Журнал / Опоздания** (если есть данные).
- Настройки: плотность ячеек, **масштаб %**, сотые в среднем, скрытие колонки «Ср. зн.».
- **История входов** — быстрый повторный вход по сохранённым фамилии/группе.

### Уведомления (Android)
- Регистрация устройства для **push-уведомлений** (через отдельный backend).
- Настройки: отдельно журнал и расписание.
- Фоновая синхронизация после закрытия приложения.

### Прочее
- Тёмная тема в расписании и части экранов.
- SEO: `robots.txt`, `sitemap.xml`, метаданные для поисковиков.
- Улучшения стабильности HTTP на Android (нативные запросы).

## В разработке (локально, ещё не в последнем push)

> Это то, что уже есть в текущей ветке, но **не** вошло в push `4391d87`. После следующего релиза этот блок перенесётся в версию выше.

### Домены и вход
- **`lk.mini-kbp.site`** — основной адрес приложения (`/app`, журнал, профиль).
- **`panel.mini-kbp.site`** — админка (`/staff/...`) **и** доступ к `/app` для проверки от имени пользователя.
- Вход через **Google**, **Telegram**, **код приглашения** (студент / преподаватель / админ).
- Профиль: сессии, выход без лишних popup.

### Журнал v2 (учитель / MiniKBP server)
- **Журнал преподавателя** в приложении и в `/staff/journal`: оценки, дни, лабораторные, ОКР, опоздания.
- Вкладка **«Лаб. / ОКР»** — отдельный фильтр с тем же редактированием.
- Зелёная подсветка только у ячеек с **«зач»**; красное **«н»** снимается при смене оценки.
- Подписи к урокам: у препода в таблице, у студента — в popup по ячейке.
- **Офлайн-просмотр**: сохранённые журнал и расписание без сети; баннер только когда сервер точно недоступен.

### Расписание (web / Capacitor)
- Полоска дней **включена по умолчанию** (как в native Java).
- Свайп между днями, автопрокрутка активного дня в полоске.
- Исправлено вылезание бейджа **«Сегодня»** за экран на телефоне.

### Приложение `/app`
- Оболочка разбита на **подгружаемые вкладки** (настройки, расписание, журнал, профиль) — быстрее старт.
- Горизонтальная **прокрутка кнопок** в журнале препода (не сжимаются в нечитаемые обрезки).
- **Тёмная / OLED-тема** для журнала преподавателя (таблица, панели, кнопки).
- Масштаб журнала % работает и для **таблицы препода**.

### Админка (`panel.mini-kbp.site`)
- Группы, студенты, предметы, преподаватели, зачисления, коды входа.
- **Назначения drag-and-drop**: перетащить группу и предмет на карточку преподавателя (как блоки в Scratch).
- Классическая форма и таблица назначений сохранены под «классический вид».

### Android (native UI)
- Отдельные **native-экраны**: авторизация, расписание с ViewPager по дням, журнал, настройки, профиль.
- Свой дизайн полей, чипов, нижней навигации — ближе к Telegram.
