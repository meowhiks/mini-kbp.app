# Расширение MiniKBP Relay

Браузерное расширение для обхода блокировки Vercel → kbp.by. Работает **только с явного согласия** пользователя в настройках приложения.

## Установка (разработка)

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика»
3. «Загрузить распpacked» → выберите папку `extension/`
4. В приложении `/app` → **Настройки** → **Сеть MiniKBP** → включите согласие

## Как это работает

1. **Ваши запросы** — расширение загружает kbp.by с вашего IP (в обход CORS).
2. **Помощь другим** — если сервер Vercel не достучался, задание уходит в очередь; расширения участников согласия выполняют fetch и отдают результат.

Разрешённые домены: только `kbp.by`.

## Сборка для публикации

Перед публика в Chrome Web Store упакуйте папку `extension/` в zip.
